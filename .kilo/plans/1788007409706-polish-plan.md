# Chismisa App Polish Plan

## Overview
Comprehensive plan to polish the Chismisa anonymous group chat app. Based on thorough codebase analysis covering 50+ files across components, hooks, actions, API routes, and styling.

---

## Phase 1: Code Organization & Architecture (High Impact)

### 1.1 Split Dashboard.tsx (1011 lines → multiple components)
**Current Issue**: Single component handles sidebar, chat, modals, DMs, groups, media, search
**Target Structure**:
```
components/dashboard/
  index.tsx                 # Main composition (100 lines)
  ChatArea.tsx              # Messages + input (200 lines)
  ChatHeader.tsx            # Group/DM header with actions (100 lines)
  MessageList.tsx           # Virtualized message list (100 lines)
  MessageInput.tsx          # Input + media picker (100 lines)
  Sidebar/
    UnifiedSidebar.tsx      # Already exists ✓
    ConversationItem.tsx    # Extracted from UnifiedSidebar
  Modals/
    CreateGroupModal.tsx    # Extracted
    JoinGroupModal.tsx      # Extracted
    InviteCodeModal.tsx     # Extracted
    NewDmModal.tsx          # Extracted
    ConfirmModal.tsx        # Extracted (leave/delete)
    SearchModal.tsx         # Already exists ✓
```

### 1.2 Split MessageBubble.tsx (919 lines)
**Current Issue**: Handles rendering, gestures, editing, reactions, media, portal overlay, emoji picker
**Target Structure**:
```
components/message-bubble/
  index.tsx                 # Main composition (100 lines)
  BubbleContent.tsx         # Text, media, reply indicator (150 lines)
  BubbleActions.tsx         # Reply, edit, delete, react (100 lines)
  ReactionBadge.tsx         # Grouped reactions (50 lines)
  ReactionOverlay.tsx       # Portal overlay + pill (150 lines)
  EmojiPicker.tsx           # Full emoji picker modal (150 lines)
  EditMode.tsx              # Inline editing (50 lines)
  SwipeGesture.tsx          # Touch gesture handling (100 lines)
  MediaAttachment.tsx       # Image/video/voice rendering (100 lines)
```

### 1.3 Unify useChat & useDm Hooks
**Issue**: 80% duplicated logic (optimistic send, reactions, delete, edit, pagination, polling, realtime)
**Solution**: Create `useConversation` generic hook with `ConversationType` parameter
```typescript
// New shared hook
function useConversation<MessageType, ConversationType>({
  fetchMessages,
  sendMessage,
  editMessage,
  deleteMessage,
  reactToMessage,
  markAsRead,
  subscribe,
  unsubscribe,
  subscribePresence,
  // ... config
})
```

### 1.4 Extract Media Picker Logic
**Issue**: Media handling duplicated in Dashboard and DmView
**Solution**: `useMediaPicker` hook with `onUploadComplete` callback

## Phase 2: Performance Optimizations (High Impact)

### 2.1 Virtualize Message List
**Current**: Renders all messages (`messages.map()`)
**Target**: Use `@tanstack/react-virtual` or custom windowing
- Only render messages in viewport + buffer
- Critical for groups with 1000+ messages

### 2.2 Optimize Re-renders
- Add `React.memo` to `TimeDivider`, `MessageBubble` children
- Use `useMemo` for `groupedReactions` (already done ✓)
- Add `useCallback` to all inline handlers in Dashboard
- Memoize `formatTypingIndicator` (already done ✓)

### 2.3 Bundle Size Reduction
- Lazy-load `EmojiPicker` (`React.lazy` + `Suspense`)
- Lazy-load `SearchModal`, `MediaPicker`
- Remove unused Lucide icons from imports
- Tree-shake emoji data (only load searched category)

### 2.4 Image Optimization
- Add `loading="lazy"` to message images
- Use `next/image` for media thumbnails
- Add blur placeholders for images

### 2.4.5 Background Sync
- Implement service worker for offline message queue
- Background sync when connection restored

## Phase 3: Accessibility (a11y) - WCAG 2.1 AA (High Impact)

### 3.1 Keyboard Navigation
- Tab order: sidebar → messages → input → actions
- Arrow keys for message navigation (up/down)
- Escape to close modals/overlays (partially done)
- Focus trap in modals

### 3.2 Screen Reader Support
- `aria-live="polite"` for new messages
- `aria-label` on icon-only buttons (search, send, react)
- `role="log"` on message container
- Announce typing indicators, new messages

### 3.3 Focus Management
- Focus input on modal open
- Return focus to trigger on modal close
- Visible focus rings (Tailwind `focus-visible`)
- Skip link for keyboard users

### 3.4 Semantic HTML
- `<main>`, `<aside>`, `<nav>`, `<section>` landmarks
- `<time>` elements for message timestamps
- Proper heading hierarchy (h1 → h2 → h3)

### 3.5 Color Contrast
- Verify all text meets 4.5:1 ratio
- Ensure focus indicators visible in both themes

## Phase 4: Code Quality & Consistency (Medium Impact)

### 4.1 TypeScript Strictness
- Enable `noUncheckedIndexedAccess` in tsconfig
- Replace `any` with proper types
- Add strict null checks for DOM refs
- Use `const` assertions for action types

### 4.2 Constants & Magic Numbers
```typescript
// Move to lib/constants.ts
const MESSAGE_MAX_LENGTH = 2000;
const GROUP_NAME_MAX_LENGTH = 50;
const POLL_INTERVAL_MS = 30_000;

const LONG_PRESS_MS = 450;
const SWIPE_TRIGGER_PX = 60;

```

### 4.3 Error Handling Consistency
- Standardize `ActionResult` type across all actions
- Create `handleActionError` utility for client
- Add error boundaries for each major section

### 4.4 Naming Conventions
- Prefix hooks with `use` (already mostly done)
- Prefix server actions with `Action` suffix
- Use `PascalCase` for components, `camelCase` for hooks/utils

### 4.5 Remove Dead Code
- Remove unused imports (Lucide icons not used)
- Remove `group-sidebar.tsx` (replaced by `unified-sidebar.tsx`)
- Remove duplicate types between `types.ts` and action files
